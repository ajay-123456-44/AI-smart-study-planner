# AI Smart Study Planner

## Project Overview
AI Smart Study Planner is a simple web application that helps students organize their study schedule.

## Features
- Enter student details
- Select subject
- Enter available study hours
- Generate a personalized study plan

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download the project files.
2. Open index.html in a web browser.
3. Enter details and generate a study plan.

## Future Enhancements
- AI-based recommendations
- Progress tracking
- Reminder notifications
